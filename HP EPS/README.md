## 📑 ساختار پیشنهادها

پیشنهادهای HP EPS بر اساس موضوع دسته‌بندی می‌شوند:

- **Code Style**
```text
HP CS 1
HP CS 2
HP CS 3
...
```

> Code Style = CS

این دسته قوانین و استانداردهای مربوط به سبک و قالب نوشتن کد HP را مشخص می‌کند.

HP EPS proposals are categorized by topic:

- **Code Style**
